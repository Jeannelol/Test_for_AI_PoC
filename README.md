# AI 对话 PoC 设计对齐（精简版）

面向快速迭代的 AI 对话页 PoC，聚焦「描述 → 生成 → 接入」的闭环，便于你在 ChatGPT 中写 prompt，直接交给 Figma / MasterGo 验证效果，再嵌入前端项目。

文档位置：`/prd.md`（当前 PRD），更多记录见 `/docs`。

## 1. 目标与范围
- **目标**：完成一个单页 AI 对话体验的可用骨架，覆盖输入、历史记录、上下文提示与响应展示。
- **不做**：复杂的多场景仪表盘、审批流、报表等重型功能，后续再扩展。

## 2. 核心角色与场景
- **前端设计 / 工程**：通过 ChatGPT 生成 UI prompt，快速在 Figma / MasterGo 产出稿件并落地代码。
- **试用用户（内部）**：在 PoC 中体验对话，验证“上下文 + 提示词 + 响应”是否顺畅。
- **场景**：打开页面 → 选择或输入上下文提示 → 输入问题 → 查看回复与历史 → 复制或导出结果。

## 3. 关键任务流（针对对话页）
1) 选择/创建会话：侧栏列表，支持新建与切换。
2) 设置上下文提示：顶部/侧栏可编辑的 prompt（如系统提示、语气、长度）。
3) 输入问题并发送：主输入区，回车发送，附带快捷键提示。
4) 查看与操作回复：气泡或卡片展示，支持复制、重新生成、反馈（👍/👎）。
5) 历史与导出：按时间排序，可搜索；导出 Markdown/文本。

## 4. 验收标准（PoC 级）
- **路径清晰**：新建会话到首个回复 ≤ 3 步；发送与重试入口显著。
- **展示简洁**：消息区域可读性高，支持代码块、引用块、链接样式。
- **响应状态明确**：发送中有进度/骨架屏；失败给出重试/复制报错信息。
- **可嵌入**：组件切分清晰（侧栏、消息区、输入区、上下文提示区），便于直接拷贝到项目。

## 5. 设计语言（简化版）
- **主色/辅色**：深蓝金融风主色 `#0D355D`，浅灰背景；警示/强调使用橙色系（隐私提示、清除数据）。
- **字体**：中文「思源黑体」，英文/数字「Inter」，字号 16/14/12，标题 20/24。
- **阴影/圆角**：卡片 `0 8px 24px rgba(0,0,0,0.08)`；圆角 12px（卡片）、8px（输入/按钮）。
- **间距**：8px 基准网格；常用 8/12/16/24。

## 6. 页面与组件（按优先级）
- **P0**：
  - 顶部：Logo/标题 + 快捷入口（导出、设置）。
  - 侧栏：会话列表（新建、重命名、删除）、搜索。
  - 主区：消息气泡（用户/AI 区分）、代码块样式、反馈按钮、复制/重试。
  - 输入区：多行输入、发送按钮、快捷键提示、文件/图片入口（预留）。
  - 上下文提示区：可折叠的系统提示编辑，常用提示模板选择。
- **P1**：
  - 消息内工具条（引用/插入链接）、消息内操作菜单。
  - 历史导出（Markdown/文本）、分享链接占位。
  - 简单主题切换（浅/深色）。
- **P2**：
  - 多列布局的“提示库”抽屉，支持拖拽到上下文。
  - 模块化卡片（例如知识来源、插件结果）的展示插槽。

## 7. 与 Figma / MasterGo 的 Prompt 模板示例
- **整体框架**：
  - “设计一个单页 AI 对话界面，含左侧会话列表、右侧消息区与底部输入区，主色 #2563EB，圆角 12px/8px，深浅灰背景分层。”
- **消息区细节**：
  - “AI 消息卡片需包含标题行（模型名 + 时间）、正文支持代码块/引用块；附带复制与重新生成按钮，悬停出现反馈（👍/👎）。”
- **输入区细节**：
  - “多行输入框，右下角发送按钮，左侧预留上传图标位；底部显示快捷键提示 ‘Enter 发送 / Shift+Enter 换行’。”

## 8. 接入前端的实现要点
- 组件拆分：`Sidebar`（会话列表）、`ContextPanel`（系统提示）、`ChatMessages`、`Composer`（输入区）、`HeaderBar`，访客弹窗组件（首次/头像点击）。
- 状态管理：会话 ID、上下文 prompt、消息列表、发送状态、错误状态。
- 交互回调：发送/重试、复制、反馈、导出；留好接口与后端对接。
- 样式变量：集中维护主辅色、圆角、阴影、间距，便于主题切换与复用。
