# 需求与想法管理台

一个基于 **Vite + React + TypeScript + TailwindCSS** 的轻量项目，用来帮你统一管理：

- 灵感和碎片想法
- 用户反馈与需求线索
- 已成型的功能需求
- 进入规划和推进中的路线图事项

## 项目特点

- **灵感采集箱**：先快速记录，不要求一开始就写得很完整。
- **需求池**：把有价值的想法整理成结构化需求。
- **路线图**：集中查看正在规划或推进中的重点事项。
- **本地持久化**：数据自动保存在浏览器 `localStorage`，无需后端即可先用。
- **快速模板**：内置“用户痛点 / 功能需求 / 路线图候选”模板，方便快速录入。
- **状态推进**：支持将条目标记为已记录、调研中、已规划、开发中、已完成。

## 适合的使用场景

- 你经常会冒出很多零散想法，想先收集起来再整理。
- 你想把“随手记”逐渐沉淀成可执行需求。
- 你需要一个简单但有结构的个人产品工作台。
- 你想先做 PoC 验证，不急着接数据库和后端服务。

## 启动方式

```bash
npm install
npm run dev
```

默认开发地址通常为：

```text
http://localhost:5173
```

## 构建产物

```bash
npm run build
```

构建后文件会输出到 `dist/` 目录。

## 后续可扩展方向

- 接入登录与多用户协作
- 增加标签过滤、排序和自定义视图
