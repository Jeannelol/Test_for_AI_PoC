## 🔹 前端开发方法论（简化版 · State-Driven Development）

本项目采用 **状态驱动开发（State-Driven Development）**，  
所有前端任务均以 `docs/ux/ux-flow-and-states.md` 中定义的 8 个状态为最小执行单元。

每轮迭代均遵循以下简化流程：

### **1. 预览（Preview）**
打开页面并观察当前 UI 的实际表现（弹窗、欢迎区、对话区、侧栏等）。

### **2. 状态评价（State Review）**
判断界面处于 S1~S8 中的哪个状态，并检查是否符合状态定义。

### **3. 轻量 UAT（Mini-UAT）**
基于该状态的关键用例进行快速测试，评估是否通过。

### **4. 总结问题 → 编写设计 Prompt（Design Prompt）**
将视觉、布局、交互问题整理成列表，编写 prompt 提供给 Figma/MasterGo 生成优化后的界面。

### **5. 代码补充（Development via Codex, with boundaries）**
根据设计稿，在严格限定的文件范围内使用 Codex 补齐 UI 或逻辑，禁止越界修改。

### **6. 回归 UAT（Regression UAT）**
再次执行该状态的全部用例，确认功能正确且未破坏其他状态。

---

**通过上述流程，项目将保持：**

- 迭代可控  
- 状态清晰  
- 可验收（UAT）  
- 设计–代码一致  
- Codex 修改的可控性与可复盘性

## 前端状态落地进度（按 UX 状态拆分）
> 对应文件：docs/ux/ux-flow-and-states.md
每个状态由「现状 → 任务拆分 → UAT」三部分组成。

### 🔹 S1 — 首次访问态（First Visit State）
- **目标**：首次访问展示访客弹窗；点击“清除所有数据”后重新进入此状态。
- **现状**：
  - 基础逻辑已实现（localStorage + guestId）
  - 样式未对齐 Figma（深蓝版需更新）
  - 清除数据后的回归路径需验证
- **任务拆分**：
  - 更新访客弹窗样式与字段顺序
  - 确认 guestInfo 判断逻辑与触发条件
  - 清除数据 → 全局状态 reset → 刷新行为一致
- **UAT 验收**（通过才算 Done）：
  - 用例 S1-1：无访客 → 自动弹窗
  - 用例 S1-2：已有访客 → 不弹窗
  - 用例 S1-3：清除数据 → 刷新 → 自动弹窗

---

### 🔹 S2 — 首页默认态（Welcome State）
- **现状**：已有初版 UI，但推荐卡片、文案未对齐设计
- **任务**：
  - 检查欢迎区布局与6个推荐卡片
  - 补齐文案与提示说明
- **UAT**：
  - 新建对话或空会话 → 必显示欢迎区
  - 推荐卡片点击 → 能进入 S7 场景态

---

### 🔹 S3 — 输入中态（User Typing）
- **任务**：
  - 空输入禁用发送按钮
  - 输入非空启用按钮
- **UAT**：
  - 输入清空 → 按钮禁用
  - 输入任意文字 → 按钮可用

---

### 🔹 S4 — 对话态（Active Conversation）
- **任务**：
  - 补齐 loading skeleton
  - 补结构化卡片占位组件（不需真实数据）
- **UAT**：
  - 用户提问 → 立刻出现用户消息
  - AI 回复 → 正常渲染 + 自动滚动到底部

---

### 🔹 S5 — 错误态（Error Banner）
- **任务**：
  - API 错误 → 显示红色提示条
- **UAT**：
  - 强制 mock 接口异常 → 出现错误提示

---

### 🔹 S6 — 合规警告态（Compliance Warning）
- **任务**：
  - 输入触发敏感词 → 显示黄色提示条
- **UAT**：
  - 输入敏感词 → 阻止发送 + 出黄条

---

### 🔹 S7 — 场景态（Scenario Mode）
- **任务**：
  - 完成推荐卡片 → 输入框自动填充示例问题
- **UAT**：
  - 点击“看大势” → scenarioKey 设定 + 输入框填充

---

### 🔹 S8 — 会话管理态（Conversation Switching）
- **任务**：
  - 修复会话切换刷新逻辑
  - 新建对话 → 回到 S2
- **UAT**：
  - 点击历史会话 → 正确加载消息
  - 新建对话 → 显示首页态
